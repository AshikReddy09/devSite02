Background image drop-in location
=================================

Add project background images in this folder. Recommended files:

- home-hero.jpg
- about-hero.jpg
- services-hero.jpg
- projects-hero.jpg
- contact-hero.jpg

Use JPG, PNG, or WebP files. Keep the images wide (at least 1600px) and
use the McRam palette as a guide: #084259, #8CBF3F, #B3D979, #F2F2F2,
and #0D0D0D.

The site applies a navy/green tint to photographic imagery so supplied
backgrounds remain consistent with the brand palette.
